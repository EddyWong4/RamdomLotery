Kit de promoción

Imágenes verticales de 1080 × 1920 para TikTok, Reels y Shorts. Las ilustraciones de las cartas son originales, hechas para esta app: puedes usarlas libremente.

1 · Elige los colores

2 · Descarga las imágenes

El navegador puede preguntar si permites descargar varios archivos.

3 · Arma el video

  1. Abre CapCut (o el editor de TikTok) y crea un proyecto 9:16.
  2. Agrega las imágenes en orden, 2 a 3 segundos cada una (la 1 un poco menos: es el gancho).
  3. Pon una transición suave y un sonido en tendencia de la biblioteca de TikTok (esos ya tienen licencia para usarse ahí).
  4. Mejor aún: intercala un clip tuyo usando la app en el celular (generar, cantar, marcar con frijolitos). Evita que se vean cartas con derechos de autor: usa las cartas provisionales o estas ilustraciones.
